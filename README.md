# PDF Xper releases

Installers for **PDF Xper**, a PDF reader and editor for macOS.

**[Download the latest version](https://github.com/Fovaie/pdfx-releases/releases/latest)**

## Install

1. Download `PDF-Xper-<version>.dmg` from the latest release and open it.
2. Drag **PDF Xper** into Applications, replacing any older version (including
   one named pdfx).
3. The first time, right-click PDF Xper in Applications and choose **Open**
   (builds are not notarized by Apple yet).

Current builds run on Apple silicon Macs.

## Updates and trial

- PDF Xper checks this repository's latest release on launch and shows a
  banner when a newer version is available. You can also use
  **PDF Xper › Check for Updates…** at any time.
- Each release is a **45-day trial** counted from its build date. After that
  the app becomes read-only (reading, searching, and Save As keep working).
  Installing a newer release from this page starts a fresh 45 days.
